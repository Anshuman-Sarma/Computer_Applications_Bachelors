OVERVIEW

This folder contains the research paper developed as part of the BCA mini project on bone fracture detection using deep learning and X-ray images.

PAPER TITLE

Performance Evaluation of Deep Learning Models for Bone Fracture Detection Using X-ray Images

AUTHORS

- Anshuman Sarma
- Nyubenlo Seb
- Owen Warlarpih
- Dr. Lal Omega Boro
- Dr. Gypsy Nandi

RESEARCH SUMMARY

The study compares five deep learning models for detecting bone fractures from X-ray images:

- DenseNet121
- ResNet50
- MobileNet
- VGG16
- EfficientNet-B7

The research uses a dataset of 8,683 X-ray images. The images were preprocessed using resizing, normalization, contrast enhancement (CLAHE), and data augmentation techniques such as rotation and flipping.

The models were evaluated using accuracy, precision, recall, and F1 score. EfficientNet-B7 achieved the highest reported accuracy in the study at 96%.

PUBLICATION STATUS

The research paper was submitted to Sadhana for consideration for publication. It was not accepted for publication.
