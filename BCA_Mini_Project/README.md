## PROJECT OVERVIEW

This mini project was developed as part of the 5th semester BCA curriculum. The objective was to analyze and compare deep learning models for automatic bone fracture detection using X-ray images.

The models were used to classify X-ray images into fractured and non-fractured categories. Their performance was evaluated using standard classification metrics.

\---

## MODELS USED

The research evaluated the following deep learning models:

1. ResNet50
2. DenseNet121
3. VGG16
4. MobileNet
5. EfficientNet-B7

\---

## DATASET INFORMATION

The dataset contains **8,683 X-ray images** divided into fractured and non-fractured categories.

The raw images are not included in this folder because of their size. A Google Drive link and dataset information are provided inside the `Dataset` folder.

\---

## TOOLS AND TECHNOLOGIES USED

1. Python
2. TensorFlow and Keras
3. NumPy
4. Matplotlib
5. Jupyter Notebook

\---

## RESEARCH PAPER

A research paper based on this project was prepared under the title:

**Performance Evaluation of Deep Learning Models for Bone Fracture Detection Using X-ray Images**

The paper compares the five models listed above. In the reported results, EfficientNet-B7 achieved the highest accuracy at 96%.

The `Research\\\_Paper` folder contains the research paper and related submission documents.

### Publication Status

The paper was submitted to **Sadhana** for consideration for publication but was not accepted.
